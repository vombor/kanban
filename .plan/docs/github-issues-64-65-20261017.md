## Initial findings

`TerminalStateMirror` already caps scrollback at 1,000 lines, but serializes its entire buffer with no byte budget.
Browser restore chunks are 16 KiB, but their splitter visits/encodes every code point. Persistent terminal instances
remain connected and process output while parked after their last panel closes. No full PTY-history persistence is
currently visible in the session manager; existing agent-owned logs must not be misrepresented as complete PTY logs.

Native QA now uses packaged shared-CDP tooling; retained `getChromiumLaunchEnv` still references an existing vendor
fonts.conf unchanged. Current readiness verifies actual PNG decoding/background pixels and interaction, not glyph ink.
Fontconfig's official format supports relative font dirs but documents cache paths separately, so do not guess that
`prefix="relative"` works for cache dirs. No live/vendor/provider file has been modified during this investigation.

## Implementation / focused evidence

Initial restore is a cached 200-row / 128 KiB tail, retaining full normal/alternate screen state where it fits and
using a bounded plain-screen/mode fallback for pathological styling. WS live frames and browser parser writes cap at
16 KiB and explicitly yield. Warm control-only restores retain queued output; stale restores/stream credits are ignored.
Closed/hidden viewers disconnect without stopping a PTY; idle browser instances cap at five. Mobile Chat visibility
is propagated by the card detail view. New launches append private per-workspace/task archives; only bounded
64 KiB / 500-line pages are read on demand, never re-executed or accumulated into the live display. Existing agent
transcripts remain untouched; pre-feature raw output cannot be retroactively recovered and is not falsely promised.

XML before a durable rewrite of known owned font/cache paths, preserving custom rules and refusing malformed XML,
symlinks or inaccessible storage. A typed maintained XML library was added; every existing dependency version is
unchanged. Native `qa tools --verify` now proves glyph geometry/ink plus multiline input at both sizes using only owned
shared-CDP contexts. No live font file was repaired, browser restarted, benchmark rerun or verdict changed.
